# 02·04 이미지 제작용 프롬프트

이 문서는 생성 전 기획 기록이다. 이후 사용자 요청으로 02는 공정 장비, 04는 팹 작업자로 방향을 바꿔 네 장을 실제 생성했다. 현재 사용한 프롬프트는 [GENERATED_PROMPTS.md](GENERATED_PROMPTS.md)를 참고한다. 아래 웨이퍼 단독·HBM 패키지 안은 현재 사용하지 않는다.

공통 출력: 진짜 알파 채널이 있는 투명 PNG(RGBA), 1:1 정사각형, 가능하면 1536px 이상. 생성 도구의 투명 배경 옵션도 활성화한다. 흰색 배경이나 체크무늬를 그린 이미지는 투명 파일이 아니다.

## 02 반도체 공정

홍익대학교 반도체 학술 동아리 HISEM 홈페이지의 ‘반도체 공정’ 섹션에 사용할 고급 3D 제품 렌더 한 장을 제작한다. 흰색·아주 옅은 청회색 홈페이지 오른쪽에 배경 없이 떠 있는 오브젝트로 배치한다.

주인공은 미세한 회로 패턴이 새겨진 원형 실리콘 웨이퍼 한 개다. 위에서 약 30도 내려다보는 3/4 시점으로, 웨이퍼의 원형 실루엣과 얇은 옆면이 모두 보이게 한다. 표면의 일부에는 규칙적인 미세 패턴을, 다른 일부에는 얇은 막의 은은한 반사를 표현해 가공의 정밀함이 느껴지게 한다. 제조 공정을 한 번에 재현하는 설명도가 아닌 상징적인 제품 비주얼이다.

브러시드 실버 가장자리, 짙은 남색 회로 패턴, 절제된 하늘색과 아주 약한 보랏빛 간섭색. 색은 HISEM의 남색 #0E1E3F와 하늘색 #7FD0F5에 어울리게 한다. 프리미엄 헤드폰 광고처럼 실물감 있는 PBR 재질과 정돈된 스튜디오 조명. 광원은 왼쪽 위의 넓고 부드러운 흰빛, 오른쪽에는 약한 청색 림라이트. 물체 전체가 선명하고, 금속 반사는 부드럽게 제어한다.

정사각형 화면 중앙에 하나의 완결된 오브젝트만 배치하고, 전체 형태를 자르지 않는다. 가장자리 사방에 약 10% 투명 여백을 둔다. 배경은 실제 알파 채널로 완전히 투명하게 출력한다. 글자·숫자·로고·워터마크, 다른 사진의 삽입, 콜라주, 작업실·기판·받침대·바닥, 배경 그라데이션, 체크무늬, 외부로 번지는 광채와 바닥 그림자는 넣지 않는다. 외곽에 흰 테두리나 검은 잔상이 남지 않게 한다. 과장된 네온·무지개색·게임 아이템 느낌을 피한다. 투명 PNG로 출력한다.

## 04 산업과 기술 동향

홍익대학교 반도체 학술 동아리 HISEM 홈페이지의 ‘산업과 기술 동향’ 섹션에 사용할 고급 3D 제품 렌더 한 장을 제작한다. HBM과 칩렛, 첨단 패키징을 연상시키는 하나의 통합 반도체 패키지를 표현한다. 흰색·아주 옅은 청회색 홈페이지 오른쪽에 배경 없이 떠 있는 오브젝트로 배치한다.

하나의 얇고 정돈된 패키지 기판 위에 중앙 로직 다이와 주변의 낮고 단정한 적층 메모리 모듈을 통합해 구성한다. 여러 칩이 흩어진 콜라주나 과장되게 높이 솟은 탑이 아니라, 하나의 설계된 제품으로 보이게 한다. 실제 제조사 제품이나 정확한 내부 구조를 복제하는 도면이 아닌 첨단 반도체를 상징하는 개념 비주얼이다. 위에서 약 30도 내려다보는 3/4 시점으로 윗면과 얇은 층 구조가 함께 보이게 한다.

브러시드 실버와 짙은 남색 #0E1E3F, 소량의 하늘색 #7FD0F5 연결 패턴, 접점에만 절제된 옅은 금색. 프리미엄 헤드폰 광고처럼 실물감 있는 PBR 재질과 정돈된 스튜디오 조명. 광원은 왼쪽 위의 넓고 부드러운 흰빛, 오른쪽에는 약한 청색 림라이트. 오브젝트 전체를 선명하게 보여주고 금속 반사와 발광을 절제한다. 02 웨이퍼 이미지와 같은 카메라 높이·조명·재질 톤으로 제작한다.

정사각형 화면 중앙에 완결된 패키지 한 개만 배치하고, 모든 모서리가 보이게 한다. 가장자리 사방에 약 10% 투명 여백을 둔다. 배경은 실제 알파 채널로 완전히 투명하게 출력한다. HBM·AI 등의 글자, 숫자·로고·브랜드·워터마크, 다른 사진의 삽입, 콜라주, 외부 회로기판·데이터센터·도시·바닥·받침대, 배경 그라데이션, 체크무늬, 외부로 번지는 광채와 바닥 그림자는 넣지 않는다. 외곽에 흰 테두리나 검은 잔상이 남지 않게 한다. 게임 아이템이나 사이버펑크 포스터처럼 만들지 않는다. 투명 PNG로 출력한다.

## 나중에 삽입할 때

1. PNG의 알파를 확인하고 원본을 보존한다. 물체에 배경이 남아 있으면 생성 도구에서 다시 처리한다.
2. `process-cutout.png`, `industry-cutout.png` 같은 새 이름으로 이 폴더에 저장한다. 현재 참고 사진 파일을 덮어쓰지 않는다.
3. `index.html`의 해당 `.scene-primary` 경로·실제 width·height·alt를 교체하고, 같은 `figure`에 `media-cutout` 클래스를 추가한다. PC 이미지는 원본 figure에서 자동 복제되므로 다른 그림을 따로 삽입하지 않는다.
4. `.media-cutout`은 배경·카드 테두리·모서리·박스 그림자를 없애고 물체 전체가 보이도록 `contain`을 사용한다. 홈페이지에서 은은한 그림자를 추가한다. 알파가 없는 현재 사진에는 이 클래스를 적용하지 않았다.
5. PC·모바일과 밝은/옅은 색 배경에서 외곽 잔상, 물체 잘림과 크기를 확인한다.
